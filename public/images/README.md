# Earth texture

`earth-blue-marble.jpg` is the Earth surface/cloud texture distributed with the Three.js examples, downloaded November 28, 2026.

Source: https://threejs.org/examples/textures/planets/earth_atmos_2048.jpg
Upstream asset: https://github.com/mrdoob/three.js/blob/dev/examples/textures/planets/earth_atmos_2048.jpg
Earth imagery credit: NASA. This is an illustrative composite, not a current satellite feed.

The texture is served locally so globe rendering does not depend on a third-party image host. Locations come from OpenSky's telescope catalog and current launch feed. Markers rotate with the surface and disappear on the rear hemisphere. Space telescopes with no ground coordinates are excluded.
